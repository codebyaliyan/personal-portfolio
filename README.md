## 📋 Project Overview

This is my professional portfolio website, built as part of the **Devixo Solutions Web Development Internship Program (Task 01)**. It showcases my personal profile, technical skills, education, projects, and contact information through a clean and modern interface.

### Key Features

- ✅ **Functional Contact Form** — Powered by Web3Forms API (no backend required)
- ✅ **Pure HTML5 & CSS3** — No Bootstrap, Tailwind, or any UI frameworks
- ✅ **Fully Responsive** — Optimized for Desktop, Tablet, and Mobile
- ✅ **Dark/Light Mode** — Pure CSS toggle with no JavaScript
- ✅ **Glassmorphism UI** — Modern, professional design language
- ✅ **Animated Elements** — Smooth scroll, hover effects, staggered entrance animations
- ✅ **Live GitHub Heatmap** — Real contribution data from my GitHub account
- ✅ **Scroll Progress Indicator** — Visual feedback as you scroll
- ✅ **Accessibility First** — Semantic HTML, ARIA labels, keyboard navigation
- ✅ **BEM Methodology** — Clean, maintainable CSS architecture
- ✅ **Form Validation** — Visual feedback using CSS `:valid` / `:invalid` states
